# 卡片与中间文件规范

## 分块提取文件

```markdown
# chunk-NNN 提取（第X章—第Y章）
## 一、角色出现
### 角色名
- 身份/别称：
- 所属势力：
- 能力/装备：
- 本块关键经历：
- 人物关系：
- 章节范围：
## 二、副本/闹鬼事件
### 事件名
- 地点：
- 起因/背景：
- 触发/进入条件：
- 涉及的鬼及其规则：
- 死亡条件与禁忌：
- 逃生/破解方法：
- 死亡名单：
- 幸存者：
- 涉及角色：
- 章节范围：
- 本块内结局/进展：
## 三、鬼
## 四、势力/组织
## 五、重要道具
## 六、术语与设定
## 七、大事记
```

## 事实等级

- **核心**：多章节、多来源或主线关键实体。
- **次要**：有明确身份和至少一项行动/关系，但不是主线核心。
- **仅提及**：只出现姓名、称呼或一次传闻，资料不足以建立完整卡。
- **待复核**：来源之间存在同名、结局、章节或身份冲突。
- **传闻**：副本或事件只在角色转述中出现，不能当作现场事实。

## 来源字段

来源至少保留：

```markdown
## 来源
- merge-04.md：第538—687章合并记录；对应分块 chunk-028—036。
- 原始章节：第601章、第609章。
```

不要写无法回溯的“根据原文”。

## 冲突记录

```markdown
## 冲突与边界
- 早期记录：……（章节）
- 后期记录：……（章节）
- 判定：资料未说明是否为同一实体，保留两种说法。
```

## 文件命名

Windows 文件名禁止 `\ / : * ? " < > |`。替换为全角符号、短横线或下划线，并在卡片中保留原始名称。文件名安全化不能改变实体主名。
