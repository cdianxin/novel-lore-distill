# 修复与审计清单

## 来源链

- [ ] 分块文本编号连续，且与已声明的分块数量一致
- [ ] 分块提取编号连续
- [ ] 每个分块八类栏目齐全
- [ ] 合并文件编号从 01 连续到实际最大编号
- [ ] 每份合并文件有八个一级栏目
- [ ] 每份终审输入均列出合并目录中的全部实际来源
- [ ] 补充文件已去重，不会与主合并文件重复输入

## 最终卡片

- [ ] 正式目录来自暂存成功产物
- [ ] 覆盖前已备份
- [ ] 人物、事件、地点、势力、物品和能力都有索引
- [ ] 根索引链接包含实际启用的分类目录
- [ ] 目录内索引链接只使用同目录相对路径
- [ ] 无空卡
- [ ] 无重复后缀卡
- [ ] 卡片含实体状态
- [ ] 卡片含来源
- [ ] 仅提及和待复核对象有显式标签
- [ ] 冲突实体有裁决记录
- [ ] 未出现的类别没有被伪造为空内容卡片

## 章节与质量

- [ ] 最小章节号等于已声明的原文首章或有解释
- [ ] 最大章节号等于已声明的原文末章或有解释
- [ ] 章节、场景或时间线中的编号错位保留为边界说明
- [ ] 统计短卡和占位字段
- [ ] 统计括号规范化重名
- [ ] 对比修复前后实体集合
- [ ] 区分确定遗漏、疑似遗漏、原文矛盾
- [ ] 没有把题材专用术语误改为通用分类

## 交付前报告

报告应写：

1. 输入文件、格式和处理范围
2. 分块、合并和终审数量
3. 实际启用的类别及各类最终卡片数
4. 索引坏链数
5. 备份路径
6. 并发峰值和失败重试情况
7. 仍需人工复核的边界
