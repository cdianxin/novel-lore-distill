# 修复与审计清单

## 来源链

- [ ] 分块文本编号连续，且与已声明的分块数量一致
- [ ] 分块提取编号连续
- [ ] 每个分块八类栏目齐全
- [ ] 合并文件编号从 01 连续到实际最大编号（数量随实际范围变化）
- [ ] 每份合并文件有八个一级栏目
- [ ] 每份终审输入均列出合并目录中的全部实际来源
- [ ] 补充文件已去重，不会与主合并文件重复输入
- [ ] 原始文件 manifest 含路径、SHA-256、大小和修改时间

## 最终卡片

- [ ] 正式目录来自暂存成功产物
- [ ] 覆盖前已备份
- [ ] 人物、事件、地点、势力、物品和能力都有索引
- [ ] 根索引链接包含实际启用的分类目录
- [ ] 目录内索引链接只使用同目录相对路径
- [ ] 所有索引中的 Markdown 链接和锚点都存在
- [ ] 每张正式卡片至少被一个分类索引覆盖
- [ ] 无空卡
- [ ] 无重复后缀卡
- [ ] 卡片含实体状态
- [ ] 卡片含稳定实体 ID
- [ ] 每条证据含来源文件、定位、证据类型、置信度和事实状态
- [ ] 卡片含来源摘要
- [ ] 仅提及和待复核对象有显式标签
- [ ] 冲突实体有裁决记录
- [ ] 未出现的类别没有被伪造为空内容卡片

## 章节与质量

- [ ] 最小章节号等于已声明的原文首章或有解释
- [ ] 最大章节号等于已声明的原文末章或有解释
- [ ] 章节、场景或时间线中的编号错位保留为边界说明
- [ ] 统计短卡和占位字段
- [ ] 统计括号规范化重名
- [ ] 对比修复前后实体集合
- [ ] `PIPELINE_STATE.md` 固定字段齐全，未把候选结果写成已完成
- [ ] 区分确定遗漏、疑似遗漏、原文矛盾
- [ ] 没有把题材专用术语误改为通用分类

## 交付前报告

报告应写：

1. 输入文件、格式和处理范围
2. 分块、合并和终审数量
3. 实际启用的类别及各类最终卡片数
4. 索引坏链数
5. 备份路径
6. 并发峰值和失败重试情况
7. 仍需人工复核的边界
8. manifest 校验结果和源文件是否可访问
9. 严格审计失败项（若有）
